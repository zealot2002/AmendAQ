## 一、评测怎么设

- **语料**：虚构《澄海精密员工手册》。跑了两档：**103 条已发布问答 / 48 题**；**211 条 / 60 题**（含 10 道必须同时跨两条以上 AQ 的题）。  
- **生成模型**：三家统一 `Qwen3.6`（AmendAQ 走 mycs 已支持接口）。  
- **判分**：程序核对义务、数字、拒答、不编造；不让模型自评。  
- **AmendAQ**：表中 **mycs** 列；始终用**整理后的已发布词条**（条件 B 也不改语料）。  
- **传统 RAG**：500 字切分、重叠 80；jieba BM25 + `BAAI/bge-large-zh-v1.5` + RRF + `bge-reranker-large` 取 **Top 5** 段。  
- **LightRAG**：1.5.8，默认 `mix` 查询；嵌入/重排与传统管线同一对。  
- **GraphRAG**：未纳入（建索引贵，且项目目前基本是维护模式）。  
- **两种条件**  
  - **条件 A**：三家都看**已发布问答**（公平比准确率）。  
  - **条件 B**：传统 RAG 与 LightRAG 看**源手册正文**；AmendAQ 仍看词条。源手册不含运营写的「手册没有这条规定」句。

整理稿里的拒答条（如住房补贴、靠窗工位）在条件 A 里对照系统也能看到；条件 B 看不到。

## 四、怎么读这些表

**没有一家在所有设定下全面更高。**

- **103 条 / 48 题 / 条件 A**：LightRAG **48/48**；AmendAQ 与传统 RAG **46/48**。  
- **211 条 / 60 题 / 条件 A**：传统 RAG **56/60**，AmendAQ **55/60**，LightRAG **54/60**。  
- **条件 B（只看源手册的对照）**：211 条时 LightRAG **56/60**，AmendAQ **55/60**，传统 RAG **54/60**。

**类型上的分化（211 条 · 条件 A）**

- 义务对错：传统 RAG **17/17** > AmendAQ **16/17** > LightRAG **14/17**。  
- 数字：LightRAG **17/18** > AmendAQ **16/18** > 传统 RAG **14/18**。  
- 拒答：传统 RAG 与 LightRAG **8/8**，AmendAQ **6/8**（103 条时曾 **8/8**，库加长、分两批读标题后变松）。  
- 不编造：AmendAQ 与传统 RAG **8/8**，LightRAG **6/8**。  
- 跨条 10 道：AmendAQ **10/10**。

**延迟与 token（211 条 · 条件 A）**

- 单题中位：传统 RAG **7.6s**，AmendAQ **21.2s**，LightRAG **33.5s**。  
- 输入 token 合计：传统 RAG **11.3 万**，AmendAQ **91.7 万**，LightRAG **100.1 万**。  
- 索引：AmendAQ **0s**（发布即索引）；LightRAG 首次 **903s**、**34** 次图谱生成。

**AmendAQ 在 211 条上丢的 5 分（条件 A）**：`shared_account`（未写全实习生）、`heat`（未写 **35℃** 起算）、`fixed_term_leave`（2 个月零 10 天应是 **2 天** 年假）、`housing_absent` / `window_absent`（拒答句式未命中判分规则）。

**表里没有、但运维会在意的事**：改一条 AQ 只改发布，不必重嵌；传统/LightRAG 改源手册后要面对切片或图谱是否仍带着旧表述。

## 五、什么时候可以考虑 AmendAQ

| 场景 | 更合适的路径 |
|---|---|
| 一本制度 / 办事指南，几十～两百条，会经常改某一条 | **AmendAQ**：发布即生效，按编号取正文 |
| 一题要同时用上两条以上规定，漏一条即错 | **AmendAQ**：本测 **10/10**；检索 Top-5 仍会在复杂题上漏 |
| 仍是原始长文档，先要搜到一段 | **传统 RAG**（本测更快、更省 token） |
| 要图索引式综合、能接受建图成本 | **LightRAG** 等（103 条条件 A 曾全对） |
| 多库全文搜词 | 三者都不是；AmendAQ 一次只读一本已选库 |

这不是公开基准冠军榜，只锁了一条传统管线和 LightRAG 1.5.8；嵌入/重排 revision 见仓库 `docs/对比测试_澄海手册*.md`。

---

**本篇小结**

1. 两档语料、两种条件、按类型 + 逐题 + 成本表均列出。  
2. 60 题总分接近（54–56），AmendAQ 赢在跨条 10 道与部分不编造，输在拒答与部分义务/数字。  
3. 若「更好」指更快更省 → 传统 RAG；若指改一条不用重建索引 → AmendAQ；若指这 60 题最高总分 → 视条件 A/B 在传统 RAG / LightRAG 间切换，差距最多 2 分。
