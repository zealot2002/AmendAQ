# 用户使用 mycs

默认使用 **智谱 GLM**（`glm-4-flash`）；也可切换 Ollama 或其它 OpenAI 兼容网关。无 Mock、无题库硬编码。

## 1. 环境

```bash
uv sync --extra dev --extra ui
cp .env.example .env   # 填写 GLM_API_KEY
export MYCS_LLM=glm
export GLM_API_KEY=你的智谱Key
export GLM_MODEL=glm-4-flash
# 或 ollama / openai 兼容网关（需 OPENAI_API_BASE）
```

## 给用户看的说法（产品文案）

| 界面用语 | 含义 |
|----------|------|
| **文档编号** | 每本上传手册的系统 ID（自动生成，无需填写） |
| **知识目录** | 按章/节拆好的目录树 |
| **目录草稿** | 已整理、可改，**问答还用不了** |
| **已上线** | 点「正式发布」后，问答才读这份内容 |
| **已入库手册** | 您上传并整理过的手册列表 |

开发文档里的 mount、node_id、draft 等是内部实现名，**界面不再展示 mount**。

## 2. 导入文档 → Wiki 草稿（目录 + 知识图谱）

```bash
uv run mycs ingest txt /path/to/手册.txt --doc-id my_company
uv run mycs wiki publish --doc-id my_company   # 或 ingest 加 --publish
```

- 默认：**TOC-first**（章/节/叶子 Wiki 草稿 + kg 叶子实体）
- UI：`uv run mycs-ui` → **Wiki 审核** Tab 编辑节点并发布
- 仅开发：`--section-only` / `--enrich-graph`（旧路径）

## 3. 提问

```bash
export MYCS_GRAPH_DOCUMENT=my_company
uv run mycs "远程办公每周最多几天？"
```

或 UI（**完整工作流**：上传 → Wiki 草稿 → 审核 → 发布 → 问答）：

```bash
export MYCS_GRAPH_DOCUMENT=my_company
uv run mycs-ui
```

打开浏览器后进入 **「① 工作流」** Tab：上传 `.txt`、生成 **Wiki 草稿**、**发布 Wiki**，再在 **「② 问答」** 提问。文档 ID 自动生成；上传文件在 `data/uploads/`。

## 4. 背后流程（泛化）

```text
ingest:  LLM 读 txt → 图谱入库
问答:    Ollama Understand → **Ollama Plan（多知识缺口 JSON）**
         → kg_* API loop → Ollama Compose → Verify
```

**新文档**：重新 `ingest txt` + 更新 `MYCS_GRAPH_DOCUMENT`。  
**新问法**：直接问；Plan 不绑具体章节，Compose 由模型基于检索结果写答案。

本地 **kg_search** 打分（title 4 / summary 2 / body 前 500 字 1、二字分词、search 后补节号）见 **[本地检索与寻址.md](./本地检索与寻址.md)**。

对客回复默认只展示「结论」段，但结论须写**完整步骤与要点**；若模型仍只写一句话，系统会把「依据」里的细则自动拼到用户可见正文（`MYCS_CHAT_SHOW_EVIDENCE=1` 可看全文含依据标题）。

## 5. 政务 demo（可选）

`uv run mycs bootstrap` 后：

```bash
uv run mycs --demo case
uv run mycs --demo policy
```

仍走 Ollama Plan/Compose + `gov_*` 表。

## 6. 集成测试

```bash
MYCS_INTEGRATION=1 uv run pytest tests/test_agent_loop.py
```
