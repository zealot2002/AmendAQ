Read the setup & limitations

Chenghai Precision is fictional. The main run uses 211 FAQ entries and a source handbook of 4,997 Chinese characters. Traditional RAG: 500-character chunks, overlap 80; jieba BM25 + BAAI/bge-large-zh-v1.5, RRF + bge-reranker-large, top 5. LightRAG 1.5.8 uses mix with the same embedding/reranker pair. GraphRAG was not tested.

AmendAQ scans titles in batches of 200 and uses the same FAQ run in A and B. The 30 cross-entry cases are the original 10 c_* plus 20 x_cross_* cases, not a separate question category. This is one fixed pipeline comparison, not a public benchmark ranking. Verification rules can miss paraphrases or falsely reject answers.
