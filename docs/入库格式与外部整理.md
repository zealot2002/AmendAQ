# 入库格式与外部整理（运营 SOP）

## 分工（简化）

| 阶段 | 谁做 | 做什么 |
|------|------|--------|
| **整理稿** | 运营 + 豆包 / 智谱 / ChatGPT 等 | 把杂乱 Word/表格/聊天记录 **归纳、去重、合并**，输出 **本规范 Markdown 或编号 txt** |
| **入库** | mycs | **只解析、不猜意**；结构不合法 → **直接失败**，不写 Wiki |

系统入库 **不调大模型**。质量门禁 = **严格语法 + `validate_canonical`**。

---

## 路径 A：FAQ / 咨询类（`.md`）

### 语法（解析器认什么）

1. 第一行：`# 文档标题`（可选，无则用文件名）
2. **章 = 业务域**：每块以 `## ` 开头一行标题（不要用它写「附录说明」除非你也希望单独成章）
3. **叶 = 单题**：每题必须 `### Q数字. 题干`（`Q` + 阿拉伯数字，全局连续为佳，如 Q1…Qn）
4. **答案**：紧跟一行 `**答：**`，后面是答案全文（可多段）
5. 禁止：用 `####` 写题、只有「问：」没有 `### Qn`、答案里没有 `**答：**`（弱匹配时易乱）

### 示例

```markdown
# 智能客服 FAQ

## 下载与安装

### Q1. 安卓在哪里下载？
**答：**
请在应用商店搜索「示例 App」下载，勿使用不明链接。

### Q2. iOS 搜不到怎么办？
**答：**
部分地区需切换 Apple ID 区域，详见官网说明。

## 账号与登录

### Q3. 忘记密码怎么办？
**答：**
登录页点「忘记密码」，按短信验证重置。
```

### 入库失败（FAQ）

- 没有 `##` 章 → 0 章 / 0 叶
- 没有 `### Q数字` → 章下无叶
- `validate_canonical`：空 body、重复编号、父子关系错误等
- 整理后 **0 条目录** → 接口报错，不落库

默认 **`MYCS_INGEST_STRICT=1`**：缺 `**答：**`、非 `Q` 题号、空 `##` 章、缺题号等 **直接入库失败**（以前只记 `ingest_notes` 仍会写入）。

## 路径 B：制度 / 员工手册（`.txt`）

1. 章：`1. 章标题`
2. 节：`1.1 节标题`，下一行起为正文
3. 子节：`1.1.1` …

入库走编号解析；FAQ 形态的 `.md` 不要混用同一份文件。

## 给豆包 / 外部大模型的 Prompt（复制即用）

```
你是企业知识库编辑。请把下面【原始材料】整理成一份 Markdown FAQ，供程序自动入库。

硬性规则（违反任一即不合格）：
1. 文首一行：# 加文档标题
2. 按业务域分块，每块仅一行：## 业务域名称（不要写「附录」「说明」除非独立成域）
3. 每一问一行：### Q1. 题干 / ### Q2. …，Q 后必须是阿拉伯数字，全文题号从 Q1 连续递增，不跳号、不重复
4. 每问下一行必须是 **答：**，随后是答案正文；禁止编造原文没有的电话、政策、链接
5. 合并重复问法为一题；矛盾处用 > **原文矛盾：** … 写在文首备注，不要擅自裁决
6. 只输出 Markdown，不要 JSON、不要代码围栏、不要「好的，如下」等废话
7. 缺页、缺题、待核实：写在文首一行 > **整理备注：** 后，勿增加没有题目的 ## 小节
8. 答案内有序列表序号连续（1. 2. 3.）；占位信息写入整理备注
9. 保存为 `.md` 再上传

【原始材料】
（在此粘贴 Word 导出、表格、聊天记录等）
```

运营流程：**外部生成 → 本地保存为 `.md` → 在 mycs「上传并整理目录」→ 失败则把报错 + 本规范一并丢回大模型改一版**。

## 与 Wiki 结构的对应

| 概念 | FAQ 稿 | Wiki |
|------|--------|------|
| 业务域 | `##` | 章（chapter） |
| 单题 | `### Qn` + `**答：**` | 叶（leaf）+ evidence |
| 编号 | 文中 Qn | 系统按章内顺序生成 1.1、1.2… |

## 自检清单（上传前 30 秒）

- [ ] 扩展名 `.md`（FAQ）或 `.txt`（手册）
- [ ] 每个业务域有 `##`，每题有 `### Q数字`
- [ ] 每题都有 `**答：**` 且非空
- [ ] 题号 Q1…Qn 连续
- [ ] 没有把「修订记录」「联系方式」误写成多余的 `##`（除非确实要单独成章）
