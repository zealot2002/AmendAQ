# 数量与上限

只使用用户问题里写出的已有数量，以及条款原文里的数字。技能说明不是新的事实。

- 条款若同时写明「新增 / 可获得 / 授予」的数量，以及「上限 / 最多至 / 不超过」的数量：最终可拥有的数量 = 已有数量 + 新增数量，且不得超过该上限。结论行只能写这一个数量。
- 算出该数量后，禁止再写「上限 − 已有」或「剩余还能增加多少」，也禁止把结论改成这个减法结果。条款原文若没有把剩余额度定义成上限减去已有，这种减法不是答案。
- 依据只解释结论里的那一个数量，不要并列两个互相否定的天数、金额或时限。
- 条款只有上限、没有新增数量时，不要自行相加。
- 对客正文只引用条款号，不要写出技能名称。
